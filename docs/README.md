## 关键结论速览

1. **技术栈**：原生 HTML/CSS/JS（ES modules）+ ECharts 5（本地 vendored），零构建、零后端、零运行时依赖；测试用 Node 内置 `node:test`。
2. **异动阈值**：±7%（龙虎榜主板口径）+ 量比 3 倍辅助；事件窗口 T−1~T+1。
3. **时间映射**：交易所时区（Asia/Shanghai）下，交易日 15:00 切分（15:00 前→当日，15:00 后→下一交易日）；非交易日→下一交易日；边界 15:00:00 归当日。
4. **标注护栏**：事实/观点/时间相关性/因果假设四层；因果假设必须带证据、置信度（上限 0.9）、不确定性；证据不足时明确输出"无法归因"，禁止编造。
5. **模拟数据**：虚构"华辰科技 600888.SH"，预埋 T_up（盘后公告）、T_down（周末利空）、T_weak（仅传闻）三个异动日，覆盖全部测试用例。
