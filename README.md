# 股价异动解释 Agent（K 线与事件时间线 + 浮动规则助手）

> 纯前端、自包含、可复现的教学演示项目。全部数据为虚构的「华辰科技 600888.SH」，不对应任何真实证券与事件，不构成任何投资建议。

## 一、启动方式

**方式一（推荐）**：任一静态服务器

```bash
# Python
python -m http.server 8000
# 或 Node
npx serve .
```

访问 `http://localhost:8000/`。

**方式二**：VS Code 安装 Live Server 插件后右键 `index.html` → Open with Live Server。

> 注意：项目使用 ES modules，直接双击 `index.html`（file:// 协议）会被浏览器 CORS 拦截，必须走 http 协议。

**测试**（Node ≥ 18，零依赖，无需 `npm install`）：

```bash
npm test        # 等价于 node --test tests/*.test.js
```

## 二、交互流程

页面分五个区域：

| 区域 | 说明 |
| --- | --- |
| A 顶部信息栏 | 股票名称/代码、交易所、时区、数据区间、图例；「重置选择」按钮 |
| B K 线图区 | 日 K 蜡烛图 + 成交量副图；异动日用图钉标注涨跌幅；事件在 K 线上方以彩色圆点标记（蓝=公告、青=行业、橙=新闻）；支持缩放/平移 |
| C 事件时间线 | 按「映射交易日」分组的纵向时间线；事件卡含类型/标签/方向；范围外事件灰显分组 |
| D 事件详情 | 标题、类型、来源（含等级）、原始时间、交易所时区时间、映射交易日、映射原因、摘要、证据列表、模拟链接 |
| E 浮动助手 | 右下角圆形按钮展开面板；随选中日输出 1~3 个影响因素 |

**联动主线**：

1. 点击 K 线异动日蜡烛 → 蜡烛背景高亮 + 时间线滚动定位到该日分组 + 详情展示该日事件 + 助手弹出因素卡。
2. 点击时间线事件卡 → 详情面板打开该事件 + K 线定位到其映射交易日。
3. 点击助手中「定位到对应事件」→ 时间线滚动并闪烁高亮该事件卡。

**演示快捷入口**（URL 参数）：

| URL | 效果 |
| --- | --- |
| `/?date=2026-10-12` | 初始选中 T_up（重大合同上涨日） |
| `/?date=2026-10-19` | 初始选中 T_down（周末政策下跌日） |
| `/?date=2026-10-26` | 初始选中 T_weak（证据不足异动日） |
| `/?demo=empty` | 空数据状态 |
| `/?demo=broken` | 异常数据状态（坏行被跳过并提示「已跳过 N 条」） |
| `/?demo=loading` | 常驻加载态（演示用） |

## 三、实现方案

### 3.1 技术栈

原生 HTML + CSS + JavaScript（ES2020 modules）+ Apache ECharts 5（本地 vendored，完全离线可用）。零构建、零后端、零 npm 运行时依赖。测试用 Node 内置 `node:test`。

### 3.2 目录结构

```
├─ index.html              # 单页入口（五区布局）
├─ data/                   # 6 个内置模拟数据文件
│  ├─ stock.json           # 股票元信息 + 异动阈值配置
│  ├─ calendar.json        # 交易日历（含虚构国庆假期）
│  ├─ kline.json           # 39 个交易日 OHLCV
│  ├─ events.json          # 12 条公告/新闻/行业事件（混合 UTC 与 +08:00 时间戳）
│  ├─ financials.json      # 半年报财务数据
│  └─ manifest.json        # 数据版本与剧情锚点说明
├─ data/broken/            # 异常数据演示集（?demo=broken 使用）
├─ src/
│  ├─ core/                # 纯逻辑（Node 可测，不依赖 DOM/图表库）
│  │  ├─ calendar.js       # 交易日历查询（二分查找 nextTradeDate）
│  │  ├─ timeMapper.js     # 时区转换 + 交易日映射规则（核心）
│  │  ├─ anomaly.js        # 异动判定（±7% 阈值 + 量比 + 手工标记并集）
│  │  ├─ evidence.js       # 证据分级与因素评分（置信度上限 0.9）
│  │  ├─ agent.js          # 规则助手（确定性输出 + 护栏文案模板）
│  │  └─ schema.js         # 数据校验（坏行剔除 + 错误收集）
│  ├─ ui/                  # 视图层（chart/timeline/detail/assistant/states）
│  ├─ utils/time.js        # Intl 时区工具（显式传时区，不依赖运行环境）
│  └─ app.js               # 装配 + 事件总线 + 联动逻辑
├─ tests/                  # 21 个断言级测试（node:test）
└─ vendor/echarts.min.js   # 本地 ECharts 5.5.1
```

### 3.3 核心规则

**异动判定**（`anomaly.js`）：

- 显著上涨/下跌：日涨跌幅绝对值 ≥ **7%**（依据：沪深交易所主板龙虎榜 ±7% 偏离值口径，见 docs/03）。
- 辅助信号：当日成交量 ≥ 前 30 个交易日均量 × 3（volumeSurge，不单独构成异动）。
- 手工预标记（`anomalyTag`）与规则识别取并集，triggers 记录命中规则。

**时间映射**（`timeMapper.js`）——题目核心规则：

| 事件发生时刻（交易所本地） | 映射结果 |
| --- | --- |
| 交易日 00:00–14:59:59（盘前/盘中/午休） | 当日 |
| 交易日 15:00:00 整 | 当日 |
| 交易日 15:00:01 及以后（盘后） | 下一交易日 |
| 非交易日（周末/节假日）任意时刻 | 下一交易日 |
| 映射日超出日历区间 | `inRange=false`，进入范围外状态 |

所有时间戳先经 `Intl.DateTimeFormat`（显式 `Asia/Shanghai`，不依赖运行环境时区）转到交易所时区，再按上表映射。每条事件产出三个时间字段：原始时间、交易所时区时间、映射交易日 + 映射原因。

**四类标签与置信度**（`evidence.js`/`agent.js`）：

- 事实（fact）/ 观点（opinion）来自数据预置；时间相关性（correlation）与因果假设（causal_hypothesis）由系统生成。
- 置信度：基础分按类型（公告/财务 0.75、行业 0.55、新闻 0.45、观点 0.2）+ 同向当日加分 + 证据条数加分 − 反向扣分，来源等级封顶（A 0.9 / B 0.6 / C 0.3），总分上限 0.9。分档：≥0.7 高 / 0.4~0.7 中 / <0.4 低。
- 护栏：窗口内无事实类证据 → 直接输出「证据不足」，禁止编造；观点/传闻因素标记「未经证实」；全部因果措辞为「可能与……有关」「因果假设，尚未经证实」，禁止「导致/推动/因为」。

## 四、已知限制

1. **阈值法局限**：固定 ±7% 未剔除大盘/板块整体涨跌（β 影响），对低波动股偏敏感、对高波动股偏迟钝；不是严谨的异常收益检验（事件研究法 AR/CAR 仅作设计依据，未实现，见 docs/03 第 3 节）。
2. **因果假设非因果**：所有「可能与……有关」均为时间相关性驱动的假设，未经任何统计检验，置信度是确定性规则评分而非概率。
3. **助手为规则模拟**：非真实 LLM，输入相同则输出相同；不支持多轮对话。
4. **单一虚拟股票**：不支持多股切换、分钟级数据、技术指标（MA/MACD 等）。
5. **时区简化**：仅支持 Asia/Shanghai（UTC+8 无夏令时）；映射规则不区分直通车/非直通车披露窗口。
6. **模拟链接**：事件来源 URL 均为虚构占位链接，不可访问真实内容。
7. **file:// 不可运行**：ES modules 受 CORS 限制，必须经 http 服务访问。
