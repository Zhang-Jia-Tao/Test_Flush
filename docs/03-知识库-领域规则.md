【已查证·官方】盘后固定价格交易：2026 年 7 月 6 日起扩至全部 A 股和 ETF，时间为每个交易日 15:05–15:30。

来源：

## 2. 上市公司信息披露时段（模拟公告时间戳的真实感依据）

【已查证·官方】

- 上交所科创板信披指南：交易日午间披露时段 7:30–12:30；盘后披露时段直通车公告 7:30–19:00、非直通车 7:30–17:00；并设非交易日披露时段。
  http://www.sse.com.cn/lawandrules/guide/stock/kcbxxpljg/c/c_20250425_10777769.shtml
- 上交所互联互通存托凭证办法明确列示：盘后披露时段 15:30 至次日 8:30（系统维护 23:30–24:00 除外）；午间 11:30–12:30。
  https://www.sse.com.cn/lawandrules/sselawsrules2025/global/slsc/c/c_20250613_10781812.shtml
- 上交所有关增加信披时段的通知：单一/连续非交易日的**最后一日** 13:00–17:00 可披露直通车公告。
  http://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20150912_3988858.shtml
- 深交所 2015 年起增设交易日早间时段（6:00–8:00）与非交易日最后一日下午（12:00–16:00）直通披露窗口。
  http://epaper.stcn.com/paper/zqsb/page/1/2015-04/08/A001/20150408A001_pdf.pdf

**对本项目的含义**：

1. 公告最常见的时间是**交易日晚间（15:00 后，集中在 16:00–22:00）**与**次一交易日早间（开盘前）**——模拟数据应主要分布在这两段，且它们按规则都映射到"下一交易日/当日"，正是测试重点。
2. 非交易日**最后一日下午**（如周日下午、假期最后一天下午）是真实披露窗口，模拟"周末利空 → 周一开盘下跌"场景有现实依据。
3. 本项目是简化规则模型：不区分直通车/非直通车，统一按"15:00 切分 + 交易日历顺延"处理（详见 05 文档）。

## 3. 异动判定阈值（双参照：监管口径 + 学术口径）

### 3.1 监管/交易所口径：龙虎榜（本项目主阈值来源）

【已查证·官方】主板龙虎榜（交易公开信息）公布条件：

- 当日收盘价格**涨跌幅偏离值达 ±7%** 的前 5 只；
- 当日价格**振幅达 15%**（(最高−最低)/最低）的前 5 只；
- 当日**换手率达 20%** 的前 5 只；
- 连续三个交易日内收盘价涨跌幅偏离值累计达 ±20%（ST/*ST 为 ±12%~15%）。

创业板口径更宽：涨跌幅 ±15%、振幅 30%、换手 30%（实践参考，证券时报电子报）。

来源：
- 上交所交易规则（2026修订）：https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml
- 深交所投教问答：https://investor.szse.cn/knowledge/t20230313_599193.html
- 中证网报道（上交所主板披露增至 5 只）：https://www.cs.com.cn/xwzx/hg/202109/t/t20210918_6205224.html

### 3.2 学术口径：事件研究法（Event Study）——设计思想参考，不实现

【已查证·学术】

- 异常收益 AR = 实际收益 − 正常（期望）收益；常用市场模型估计期望收益；事件窗内累计异常收益 CAR 用于衡量事件影响。综述见 arXiv 1506.02431：https://arxiv.org/html/1506.02431v2
- 单股事件研究中，CAR 超过 ±2~3% 常被视为有经济意义；统计显著性常用 p<0.05，但"95% 阈值是政策选择而非科学默认"。
  https://calcxi.com/cumulative-abnormal-return/ ；https://www.eventstudytools.com/litigation
- 极端收益（tail event）的另一类做法是**滚动窗口分位数**（如 252 日滚动、1%/5% 分位），避免不同股票波动率不可比：https://www.extremereturn.com/ ；ASA 论文（252 日滚动窗定义极端收益）：https://amstat.tandfonline.com/doi/full/10.1080/15427560.2026.2620420

### 3.3 产业实践口径（交叉验证）

【实践参考】恒生聚源"异动归因"专业技能的统一阈值：个股价格 >7% 或涨停；成交量 >30 日均量 3 倍；行业 >3%；概念 >4%；指数 >2%。归因维度：消息面（T−1~T+1 新闻/公告）、资金面、技术面、情绪面，估值面可选；"无明确证据时标注'原因不明'，不强行归因"。

## 4. "事实 / 观点 / 时间相关性 / 因果假设"标注框架

### 4.1 学术蓝本：Stock Pattern Assistant（SPA）

【已查证·学术】论文 *Stock Pattern Assistant: A Deterministic and Explainable Framework for Structural Price Run Extraction and Event Correlation in Equity Markets*（arXiv:2512.15008）与本题高度同构，给出可直接借鉴的工程化护栏：

- 事件模型 E = {(τ, ℓ, c)}：时间戳、类别、描述；事件侧做**时区统一、交易日历对齐、去重、schema 标准化**。
- 价格 run 与事件用**对称时间窗** W=[s−δ, e+δ]（δ 默认 2 个交易日，1~3 稳定，≥4 会混入无关事件）对齐；对齐结果**只表述时间共现，禁止因果归因**（"coincided with / occurred during"，不得用 "caused"）。
- 解释层硬性护栏：① 不做前瞻/预测；② 不做因果归因；③ 只用提供的字段，禁止注入外部知识；④ 确定性输入 → 确定性输出；⑤ 全链路日志可审计。
- 无事件对齐时如实表述"information-sparse environment / technically driven momentum"，不硬凑解释。
- 论文同样使用 curated、timestamped 的**手工策划样本事件**（本题的模拟数据要求与其一致），时间戳统一到交易所时区。

来源：https://arxiv.org/pdf/2512.15008v1

### 4.2 事实/观点判据与证据分级

【实践参考】"财经新闻鉴真"技能（系统化的中文金融声明核查框架）：

- 事实 FACT：可客观验证的陈述——财报数据、已发生公开事件（并购/高管变动/产品发布）、监管文件；信号词："财报显示""公告称""数据为"。
- 观点 OPINION：主观判断与预测——"被低估""有望""可能""据传""分析师认为""市场认为"。
- 因果关系声明 CAUSATION 验证难度最高，需要：① 直接证据（官方文件明确表述因果、监管认定）；② 时间顺序（先因后果）；③ 逻辑一致性；④ 排除其他解释。
- 证据等级（人证）：A 监管机构声明 95% / B 公司正式公告 85% / C 高管公开发言 70% / D 专家/分析师 50% / E 匿名未证实消息 20%；物证：A 监管审核文件 98% / B 审计财报 90% / C 第三方统计 75% / D 内部文件 60% / E 截图录音 30%。
- 反模式"因果崩溃"：只验证了"X 发生"和"Y 存在"，就接受"X 因为 Y"——金融市场充斥事后归因谬误。修复：要求直接证据、检查先后顺序、排除同期其他事件。
- 置信度分级：CERTAIN 90–100 / HIGHLY_PROBABLE 75–89 / PROBABLE 60–74 / UNCERTAIN 40–59 / LIKELY_FALSE 20–39 / FALSE 0–19。

来源：https://skillhub.cloud.tencent.com/skills/user_89306994/china-financial-claim-analyzer

【已查证·学术】新闻事实核查的学术标注传统：

- 区分 claim（可验证、归因于外部来源的事实陈述）与 non-claim（主观/推测语句）（ClaimPT，arXiv:2601.19490）：https://arxiv.org/html/2601.19490v2
- 事实陈述再按是否引用外部证据分 Fact_Appeal / Fact_No_Appeal（FactAppeal，arXiv:2510.10627）：https://arxiv.org/html/2510.10627
- 核查结论分级通行做法：True / Mostly True / Partly True / Misleading / Unsupported / False（即"无法证实"与"证伪"必须分开）：https://sabujkundu.com/category/2026/
- 新闻业置信度标注：verified / probable / disputed / unsubstantiated，并要求记录定级理由（"fake certainty"是主要错误）：https://www.elevify.com/en-ph/courses/arts-design-and-communication/journalism/news-reading-course-87734

### 4.3 本项目四类标签落地判据

| 标签 | 落地判据（模拟数据如何打标） | 视觉 |
| --- | --- | --- |
| 事实 fact | 事件本体为已发生且可核验：公司公告（合同/业绩预告/风险提示）、财报数字、监管动作、已发生的行业政策发布；来源等级 A/B | 蓝色标签 |
| 观点 opinion | 评级、目标价、"有望/预计/据传"、自媒体解读、网传截图；来源等级 D/E | 橙色标签 |
| 时间相关性 correlation | 系统对"事件映射日 ∈ 异动日 T−1~T+1 窗口"这一**事实关系**的标注，措辞模板："该事件于 X 日（盘后/非交易日顺延）映射至 Y 交易日，与 Z 日异动在时间上相邻，仅为时间相关，不构成因果" | 青色标签 |
| 因果假设 causal_hypothesis | 仅 Agent 面板生成；必备字段：`evidenceIds`（≥1 条事实类证据才允许"中"以上置信度）、`confidence`、`direction`（利好/利空/中性）、`reasoning`（依据要点）、`uncertainty`（不确定性提示，固定句式库）、`alternativeExplanations`（竞争解释，有则必列） | 紫色标签 + 置信度条 |

置信度规则（确定性可计算，与 05 文档伪代码一致）：

- 基础分：事实类公告/财报 0.75；行业事件 0.55；主流媒体新闻 0.45；观点/传闻 0.2。
- 距离权重（按事件映射日相对异动日的交易日偏移）：当日 +0.10；前一交易日 +0.04；后一交易日 +0.02。同向事件享受全额距离权重，中性事件取一半，反向事件不加分并扣分。
- 调整：每多一条独立证据 +0.1（上限 0.9）；存在反向/竞争证据 −0.15~0.3；窗口内无事实类证据 → 封顶 0.3 并直接输出"证据不足"。
- 来源等级封顶：A 级 0.9 / B 级 0.6 / C 级 0.3；观点或 C 级来源封顶 0.3。
- 分档：≥0.7 高 / 0.4–0.7 中 / <0.4 低；任何档位都必须带不确定性提示，不允许出现"确定"措辞（上限 0.9）。

> 简化说明：本项目采用 **3 级证据体系（A/B/C）**，将 4.2 节人证/物证的 5 级（A–E）做了归并——D 级（专家/分析师发言）与 E 级（匿名消息）归入 C 级，B 级（公司正式公告）归入 A 级。因此下文提到观点类来源"等级 D/E"时，在本项目中一律按 C 级处理。

固定文案约束（代码中做模板，不允许自由发挥）：

- 因果：「可能与……有关（时间相邻，依据：……；不确定性：……）」
- 相关性：「同期发生，仅构成时间相关」
- 证据不足：「该交易日未检索到达到证据标准的可核实事件，无法给出可信归因；历史上无明显利好/利空的异动也可能由资金面、情绪面或技术面因素驱动，本演示未纳入这些数据」
